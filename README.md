<h2>▶️ How to Compile and Run Locally</h2>

<p>Compile all Java files into the <code>out</code> directory:</p>

<pre>
javac -d out $(find src -name "*.java")
</pre>

<p>Run a specific solution:</p>

<pre>
java -cp out &lt;ClassName&gt;
</pre>

<p>Example:</p>

<pre>
java -cp out DateTime
</pre>
